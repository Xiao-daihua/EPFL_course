
\subsection{基础量子计算}
\hlr{pauli矩阵分解}

pauli矩阵分解可以通过矩阵的norm来描述，我们用Tr来定义矩阵的内积：
\begin{align}
  \langle A|B \rangle =\mathrm{Tr}(A^{\dagger}B)
\end{align}
于是pauli基下面就可以写作：
\begin{align}
  \rho = \displaystyle\frac{1}{2} (Tr(\rho)I + \sum_{i=1}^3
  \mathrm{Tr}(\rho \sigma_i)\sigma_i)
\end{align}
也就是说我们之前讨论的$ r_i = \mathrm{Tr}(\rho \sigma_i) $。

\hlr{量子计算基础}

对于量子计算来说，我们需要manipulate qubit
system。我们可以通过量子门来进行manipulate。\textbf{量子门是一堆Unitary
Operator}我们可以通过一系列的量子门来进行量子计算。

\bigskip
\hlr{Unitary Operator的矩阵表示}

对于一个Unitary的算符我们可以在使用矩阵进行表示。对于computation
basis我们为每一个基赋予一个向量，比如对于一个single qubit的系统来说：
\begin{align}
  \ket{0} = (1,0) ,\quad \ket{1} = (0,1)
\end{align}
而我们定义一个Unitary算符的矩阵表示为：$ U_{ij} = \bra{i} U \ket{j} $。于是我们可以知道basis在矩阵表示下满足变换关系：
\begin{align}
  U\ket{j} = U_{ij} \ket{i}
\end{align}
对于一般的向量我们可以使用这一组basis进行展开，写作$ \ket{\psi} = v_i \ket{i} $使用向量表述为$
(v_1, ... , v_n)^T $。那么Unitary演化完全可以写作分量的演化也就是：
\begin{align}
  v'_i = U_{ij} v_j
\end{align}
我们注意基的关系是求和在第一个指标的，而向量的关系是求和在第二个指标的。我们可以进行简单的计算证明：
\begin{align}
  U \ket{\psi} = U v_j \ket{j} = v_j U_{ij} \ket{i} = v'_i \ket{i}
\end{align}

\bigskip
\hlr{单比特门}

下面介绍几个比较重要的single qubit gate：
\begin{itemize}
  \item \textbf{Pauli Gate}：$ X=\sigma_x, Y=\sigma_y, Z=\sigma_z $
  \item \textbf{Hadamard Gate}：$ H=\frac{1}{\sqrt{2}}
    \begin{pmatrix}1&1\\1&-1
    \end{pmatrix} $
\end{itemize}
Hadamard Gate的作用是把$ |0\rangle $变成$ |+\rangle $，把$ |1\rangle $变成$
|-\rangle $。也就是把Z基变成X基。我们有：
\begin{align}
  HXH=Z, \quad HYH=-Y, \quad HZH=X
\end{align}
这样的关系让我们可以通过这个Gate改变测量方向。

\subsection{Purification}

\hlr{Purification基本定义}

对于一个mix state我们可以通过引入辅助系统来把这个mix state变成pure
state。这个过程我们称为purification。\thm{任何一个Generic Mix State $ \rho_a
  $都存在一个state $ \ket{\psi_{AB}} $使得：
  \begin{align}
    \rho_A = \mathrm{Tr}_B(|\psi_{AB}\rangle\langle\psi_{AB}|)
  \end{align}
}
purification并不是唯一，但是存在一个general的构造方法：
\begin{itemize}
  \item 首先把$ \rho_A $进行谱分解：
    \begin{align}
      \rho_A = \sum_i p_i |i_A\rangle\langle i_A|
    \end{align}
  \item 然后引入一个辅助系统B，构造一个纯态：
    \begin{align}
      |\psi_{AB}\rangle = \sum_i \sqrt{p_i} |i_A\rangle |i_B\rangle
    \end{align}
\end{itemize}
\rmk{
  注意purification前后存在一个$ \sqrt{p_i} $的区别，记得开根号！！
}
这个方法下我们的B系统的维度至少和A系统的rank一样大（也就是A系统有非0本征值的维度！）并且这是进行purification的最小维度！！
\begin{align}
  \mathrm{dim}(\mathcal{H}_B) \geq \mathrm{rank}(\rho_A)
\end{align}
不会比这个小，否则就会丢失信息。

\bigskip
\hlr{Pure State Decomposition for Purification}

其实我们purification并不一定需要谱分解，对于一般的量子态我们可以decompose成为一堆pure
state的组合【注意，不一定是谱分解只是刚好写作一些pure state的下面这样的组合】：
\begin{align}
  \rho_A = \sum_i p_i |\psi_i\rangle\langle\psi_i|
\end{align}
这里我们对于$ \ket{\psi_i} $没有任何要求，只要是个纯态即可。那么我们都可以找到下面的purification：
\begin{align}
  |\psi_{AB}\rangle = \sum_i \sqrt{p_i} |\psi_i\rangle |i_B\rangle
\end{align}
只不过是可能会需要引入更大的B系统。

\bigskip
\hlr{Schmidt Decomposition}

其实对于任意bipartite的pure state我们可以写作一种diagonalized的形式。我们称之为Schmidt Decomposition：
\thm{
  Schmidt Decomposition

  对于任意的一个bipartite pure state $ |\psi_{AB}\rangle \in \mathcal{H}_A
  \otimes \mathcal{H}_B $，我们可以找到A系统和B系统的两个正交归一化基底$ \{|i_A\rangle\},
  \{|i_B\rangle\} $使得：
  \begin{align}
    |\psi_{AB}\rangle = \sum_i \sqrt{p_i} |i_A\rangle |i_B\rangle
  \end{align}
  其中$ p_i \geq 0 $并且$ \sum_i p_i = 1 $。
}
注意我们要求的是分解系数的平方和为1，不是系数和！

\bigskip
\hlr{Purification After Evolve}

我们考虑对于仅仅对于用于purify $ A $系统的辅助系统 $ B
$系统进行一个unitary演化，我们会发现演化后的purifictaion仍然是一个purification！\thm{
  Evolution on the Purification System
  \begin{align}
    \rho_A = \mathrm{Tr}_B((I_A \otimes U_B)
    |\psi_{AB}\rangle\langle\psi_{AB}| (I_A \otimes U_B^\dagger))
  \end{align}
  也就是说对于一个量子态$ \rho $的purification $ \ket{\psi_{AB}}
  $，我们可以通过在B系统上进行任意unitary演化来得到另外一个purification。
}
证明则需要用partial trace的定义，然后使用分量展开。

更强大的是这个定理存在一个更强的逆定理：
\thm{\label{thm:purification-uniqueness}
  Purification Uniqueness Theorem

  对于一个量子态$ \rho_A $的两个在\textbf{相同维度的辅助系统}上的purification $
  |\psi_{AB}\rangle, |\phi_{AB'}\rangle $，那么存在一个unitary演化$ U_{BB'} $使得：
  \begin{align}
    |\phi_{AB'}\rangle = (I_A \otimes U_{BB'}) |\psi_{AB}\rangle
  \end{align}
}
证明需要用到Schmidt Decomposition。我们对于两个purification都进行Schmidt
Decomposition，由于他们是同一个mixed state的purification，因此他们必然可以写作:
\begin{align}
  |\psi\rangle=\sum_i\sqrt{\lambda_i}\left|i\right\rangle_A\otimes|i\rangle_B\quad
  |\psi\rangle=\sum_i\sqrt{\lambda_i}\left|i\right\rangle_A\otimes|i^{\prime}\rangle_B
\end{align}
的形式。由于$ \ket{i} $和$ \ket{i'} $都是B系统的正交归一化基底，因此必然存在一个unitary变换$
U_{BB'} $使得$ |i'\rangle = U_{BB'} |i\rangle $。带入上面的式子就可以证明定理。

\bigskip
\hlr{Schmidt Decomposition of Purification}

实际上任意的纯化都存在一个Schmidt分解，我们有定理:
\thm{
  对于量子态$ \rho = \sum_i \lambda_i \ketbra{i}{i} $其purification $
  |\psi_{AB}\rangle $我们总能找到A系统和B系统的正交归一化基底$ \{|i_A\rangle\},
  \{|i_B\rangle\} $使得：
  \begin{align}
    |\psi_{AB}\rangle = \sum_i \sqrt{\lambda_i} |i_A\rangle |i_B\rangle
  \end{align}
}

\subsection{Proper and Improper Mixture}

对于同一个density matrix表达的state我们很可能有不同的实现或者理解方式，比如对于一个maximally mixed
state $ \rho = \frac{1}{2}I $，我们可以有两种理解：
\begin{itemize}
  \item \textbf{Proper Mixture}：我们可以把这个态理解为$ |0\rangle $和$ |1\rangle
    $我们各自有50\%的概率进行制备
  \item \textbf{Improper Mixture}：我们也可以把这个态理解为一个entangled态$
    \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle) $的一个子系统。
\end{itemize}
两者的物理完全不一样的！
\begin{itemize}
  \item Proper Mixture是经典的，他是源于我们对于制备情况的无知
  \item Improper Mixture是对于一个纠缠态的子系统的表述
\end{itemize}

\subsection{POVM Measurement}

\hlr{回顾怎么测量经典系统}

对于一个经典系统，所谓\textbf{测量}就是我们去问这个系统一个问题，然后得到一个答案。
\begin{itemize}
  \item 每一个问出的问题可以通过一组向量进行表达：$ \{ \vec{m_k}\} $每一个向量$ \vec{m}_k
    $代表一种可能测量结果。这个向量需要满足两个条件：
    \begin{itemize}
      \item $ \vec{m}_k $的所有分量都是非负的
      \item $ \sum_k \vec{m}_k = (1,1,...,1) $，也就是所有可能结果的向量和是一个全1向量
    \end{itemize}
  \item 测量得到k结果的概率是$ p_k = m_k \cdot p  $，其中$ p $是用来描述经典状态的向量其分量表示了每一种状态出现的概率。
\end{itemize}

\bigskip
\hlr{POVM Measurement 的定义}

POVM Measurement 就是对于上面的情况的推广，下面给出详细的定义要求：
\defi{POVM测量

  对于一个量子系统我们可以用一个密度矩阵进行描述$ \rho $。下面我们对其进行测量：
  \begin{enumerate}
    \item 对这个量子系统问出的一个问题可以数学上对应这一组矩阵$ M_k $这组矩阵需要满足下面的条件：
      \begin{itemize}
        \item 每一个$ M_k $都是半正定矩阵，也就是本征值$ \geq 0 $
        \item $ \sum_k M_k = I $【注意是矩阵直接求和出来Id】
      \end{itemize}
    \item 对于某一个系统$ \rho $，测量得到k结果的概率是：
      \begin{align}
        p_k = \mathrm{Tr}(\rho M_k)
      \end{align}
  \end{enumerate}
}
注意，POVM对于每一个矩阵本身并不要求矩阵是Hermite或者对于Trace有要求，仅仅要求每一个矩阵都是半正定矩阵！
\rmk{
  注意！数学上半正定矩阵对于Hilbert Space来说任意半正定矩阵必然是Hermite的，因此我们的POVM其实里面的矩阵必然是Hermite矩阵！！
}
其实这里我们可以知道一些关于合法POVM测量的性质：
\begin{align}
  \tr(M_k \rho) \leq \tr (\rho)  = 1
\end{align}

\bigskip
\hlr{Projective Measurement as a special POVM}

我们定义projective measurement是一个特殊的POVM测量。需要满足其中矩阵$ M_k $是正交归一化的投影矩阵：$
M_i M_j = \delta_{ij}M_i $。
对于一个d维度的系统，我们需要有d个这样的投影矩阵。并且我们知道\textbf{投影矩阵必然是Hermite的！}

对于测量结果，我们之前讨论的exprectation value可以这样的到。我们为每一个测量结果k赋予一个数值$ \lambda_k
$作为一个「具体测量出来的数」，下面给出exprectation value的计算：
\begin{align}
  \sum \lambda_k p_k = \sum_k \lambda_k \mathrm{Tr}(\rho M_k) =
  \mathrm{Tr}(\rho \sum_k \lambda_k M_k)
\end{align}
我们定义$ \sum \lambda_k M_k $也就是一个Hermite矩阵，我们把他叫做observable。这就和量子力学里面讨论对应上了。
此外可以研究测量后系统的状态，根据量子力学的公理体系，我们会发现projective measurement后系统的状态变成：
\begin{align}
  \rho' = \frac{M_k \rho M_k}{\mathrm{Tr}(\rho M_k)}
\end{align}
这是在测量到k结果之后系统的状态。【其中我们使用了一个归一化捏！保证我们的$ \rho' $密度矩阵是$ Tr = 1 $的】
\rmk{
  注意！这个式子仅仅对于projective measurement成立，对于更一般的POVM测量后的演化后面会进行讨论。
}

\bigskip
\hlr{State Discrimination Problem}

下面思考一个问题，我们现在手里有一个量子态，可能是$ \ket{0} $也可能是$
\displaystyle\frac{1}{\sqrt{2}}(\ket{0}+\ket{1}) $。使用【唯一一次测量】试图确认我们到底是哪一个态！！

\textbf{答案是：不可能！！我们永远不能仅仅一次测量就能保证确认是某一个态！！}

但是我们可以通过设计一个测量方案来最大化我们正确识别的概率！！这个问题就是State Discrimination Problem。我们选择下面POVM：
\begin{align}
  M_1 = a |1\rangle\langle1|, \quad M_2 = b |-\rangle\langle-|,\quad
  M_3 = I - M_1 - M_2
\end{align}
并且给出约束条件$ a, b \geq 0  $同时选择的$ a,b $需要保证$ M_3 $是半正定的！！【这个约束条件很重要！！】在这个测量方案下:
\begin{itemize}
  \item 得到结果1我们知道手里是$ \displaystyle\frac{1}{\sqrt{2}}(\ket{0}+\ket{1}) $；
  \item 得到结果2我们知道手里是$ \ket{0} $；
  \item 得到结果3我们就不知道了！！【这个结果3我们称为inconclusive result】。
\end{itemize}

一个值得讨论的问题是：我们怎么选择$ a,b $来最大化我们正确识别的概率呢？
\bigskip

首先我们需要计算成功识别出来是某一个态的概率是多少。我们可以使用下面的定义：
\defi{成功识别概率

  由于两个态都是随机1/2概率出现的，我们设计了一个判断方式保证，Measure出来1结果为识别出了$ \psi_2
  $态，定义Measure出来2结果为识别出了$ \psi_1 $态。那么成功识别概率为：
  \begin{align}
    \begin{gathered}P_{\mathrm{correct}}=\frac{1}{2}P(\mathrm{correct}|\psi_1)+\frac{1}{2}P(\mathrm{correct}|\psi_2)\\=\frac{1}{2}\langle\psi_1|M_2|\psi_1\rangle+\frac{1}{2}\langle\psi_2|M_1|\psi_2\rangle
    \end{gathered}
  \end{align}
}
然后我们进行一个假设：\textbf{假设$ a = b $}也就是说$ M_1, M_2 $这两个POVM有一样的系数。于是我们计算$
M_3 $的本征值，根据半正定的条件我们可以得到两个POVM系数一样的最大化正确测量的解：
\thm{一般两个量子态的State Discrimination Problem的最优解

  对于一般的两个量子态$ |\psi\rangle, |\phi\rangle $，我们可以通过下面的POVM测量来最大化正确识别概率：
  \begin{align}
    \begin{aligned}&F_{\psi}=\frac{1}{1+|\langle\varphi|\psi\rangle|}|\varphi^\perp\rangle\langle\varphi^\perp|\\&F_{\varphi}=\frac{1}{1+|\langle\varphi|\psi\rangle|}|\psi^\perp\rangle\langle\psi^\perp|\\&F_{?}=\mathrm{I}-F_\psi-F_\varphi=\frac{2|\langle\varphi|\psi\rangle|}{1+|\langle\varphi|\psi\rangle|}|\gamma\rangle\langle\gamma|,
    \end{aligned}
  \end{align}
  其中量子态是：
  \begin{align}
    |\gamma\rangle=\frac{1}{\sqrt{2(1+|\langle\varphi|\psi\rangle|)}}(|\psi\rangle+e^{i\arg(\langle\varphi|\psi\rangle)}|\varphi\rangle).
  \end{align}
}
比如对于上面区分$ \ket{0}, \ket{+} $这样的两个态，我们可以选择：
\begin{align}
  M_1=\frac{\sqrt{2}}{1+\sqrt{2}}|1\rangle\langle1|,\quad
  M_2=\frac{\sqrt{2}}{1+\sqrt{2}}|-\rangle\langle-|,\quad M_3=I-M_1-M_2.
\end{align}
这样的一个解！

\bigskip
\hlr{Convex Mixture of Projective Measurement}

我们发现如果把一些projective measurement进行convex
mixture，我们会得到一个POVM测量！！那么这个POVM的意义是什么呢？比如我们有两个projective measurement：
\begin{align}
  M_A = \{ |0\rangle\langle0|, |1\rangle\langle1| \}, \quad M_B = \{
  |+\rangle\langle+|, |-\rangle\langle-| \}
\end{align}
我们可以构造一个POVM测量：
\begin{align}
  M = p M_A + (1-p) M_B = \{ p|0\rangle\langle0|,
  p|1\rangle\langle1|, (1-p)|+\rangle\langle+|, (1-p)|-\rangle\langle-| \}
\end{align}
这个convex mixture的POVM的定义是说我们有一定概率进行某一个projective
measurement，同时也有一定概率进行另一个projective measurement！

\question{怎么理解projective measurement 是一个特殊的POVM？}

我目前的理解是Projective
Measurement仅仅允许测量某一个密度矩阵表示的态，【到一个纯态上面的概率】。因为我们的projective operator其实就是一个纯态的投影。

但是一般的POVM是允许我们讨论一个混态是某个混态的概率的。这个样子，我们量子体系可以问的问题就更多了！！能测量的问题就更多了！
